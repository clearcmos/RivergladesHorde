# Changelog

## v0.3.2

- Bristle Hills Bandits is offered at the second Kreza visit only; she does not have it at the first.
- Show Them How It's Done is offered only after Food for the Taking, which is when Krom'rosh gives it, so the early "skip this if not offered" step is gone.
- Renamed to Riverglades Horde, since CurseForge does not allow a release stage in a project name. It is still experimental. RXP lists the guide under the new name, so pick it again once, then click your current step in RXP's step list.
- Quest items you use (Wood Bundle, Makeshift Stickin' Spear, Remote Explosive Charge) get RXP's clickable item button on their steps.
- If a Farholde Scouting Report drops, a step offers to start it and the next Krom'rosh visit turns it in.
- Each hunting area is one step that lists every objective there with live counters, instead of a "while you're here" step plus a "finish" step for the same item. Objectives for quests you don't have are skipped.

## v0.3.1

- Initial release. If you installed an earlier copy by hand, delete its `CMOS_Riverglades` folder.
